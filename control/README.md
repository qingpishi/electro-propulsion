# Control subsystem

Current motor-control principles:

- four independently controlled stator faces;
- main simultaneously active longitudinal stator segments use equal current;
- segment handover must preserve thrust continuity and magnetic-field continuity;
- the fourth-segment pre-excitation architecture remains OPEN;
- 3 Hz is not the maximum-thrust slip point; the 40 m/s fixed-current peak is near 2.44 Hz and the normal operating schedule remains to be optimized.
